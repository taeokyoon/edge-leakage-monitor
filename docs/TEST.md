## 10. 시스템 테스트 기록 (실제 브로커·웹·디바이스, e2e)

### ST-01. 가상 수리 옵션 `--repair-on-ack` (2026-11-08)

- 목적: 점검권고 → ack 뒤 "수리했다고 가정"하는 시험 옵션이 의도대로 동작하는지, 옵션이 없을 때는 기존 요구사항대로 경보가 다시 나는지 확인
- 관련 요구사항: STK-05b(ack하면 정상), SWR-ST-05(점검권고는 ack로만 정상), SWR-ST-07(ack 뒤 D1 재적용)
- 기법: 요구사항 기반 테스트, 대조군 비교(옵션 있음 / 없음)
- 환경: PC(WSL), 보안 브로커 8883, 웹 서버 8000, 시나리오 `sharp_rise`, 판정 AI(linear), 배속 ×1440
- 증거: 대시보드 화면 캡처 2장 (그래프·알림 이력)

1.
   - 번호 - ST-01-01
   - 조건 - 옵션 있음: `--scenario sharp_rise --repair-on-ack`
   - 절차 - 점검권고가 뜨면 대시보드 "점검 확인 (ack)" 클릭
   - 기대 결과 - ack 즉시 정상, 누설전류가 정상 범위로 복귀, 이후 경보 재발 없음
   - 실제 결과 - 주의 02:12:54 → 점검권고 06:15:05 → ack 18:44:08 정상. 누설전류 약 11mA → 약 4.2mA로 떨어진 뒤 AI 예상값(점선)과 겹침, 이상 점수 0.12. 가상 11-11 04:10까지(ack 뒤 약 33시간) 경보 재발 없음
   - 판정 (테스터) - 합격
   - 비고 - 전류가 한 샘플 만에 떨어짐: 수리를 ack 즉시로 단순화한 알려진 한계

2.
   - 번호 - ST-01-02 (대조군)
   - 조건 - 옵션 없음: `--scenario sharp_rise`
   - 절차 - 점검권고가 뜨면 대시보드 "점검 확인 (ack)" 클릭
   - 기대 결과 - ack 즉시 정상, 전류는 높은 그대로라 D1(120분) 뒤 주의, 이어서 D2(240분) 뒤 점검권고 재발
   - 실제 결과 - 주의 02:12:07 → 점검권고 06:14:54 → ack 09:28:55 정상 → 주의 11:29:30 (ack 뒤 2시간 0분 35초) → 점검권고 15:31:23 (주의 뒤 4시간 1분 53초)
   - 판정 (테스터) - 합격
   - 비고 - 초 단위 차이는 샘플 주기(실제 1초 = 가상 24분) 안의 오차
